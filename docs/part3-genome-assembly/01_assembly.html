Genome assembly

To start this tutorial, make sure you’re connected to Crunchomics as discussed in the computational setup episode. As always, let’s organize ourselves by creating a new directory for this tutorial session, in your MDA directory. Also, let’s create a data/ directory

cd personal/MDA/
mkdir genome-assembly
cd genome-assembly/
mdir data

To assemble a genome, we need reads. For this tutorial, the reads are stored on Crunchomics. There are different read datasets, and the teacher will assign to you which dataset you should copy. Some datasets contain long Nanopore reads, while other datasets contain short Illumina reads. In addition, different subsets of the data were made by the teaching team (resulting in low and high sequencing depth datasets).If you want to work together you can download the same dataset as your neighbour (maximum group size = 2!). You can discuss the steps, but both of you should process the data.

Copy your read dataset into to the data directory in your workdirectory. Replace the XY with the dataset number!

cp /zfs/omics/projects/education/MDA-materials/genome-assembly/reads/dataset_XY.fastq data/

Depending on if you have Illumina data or Nanopore data, you will need a different assembly tool. Also, the structure of the output files will look different. Note: in contrast to the RNA-seq tutorial, this tutorial uses real datasets, and the assembly jobs may take a while! Remember from the lecture, assembling a human genome with longread data takes more than 2000 computer-hours! To speed things up, bioinformatics tools can often use more threads at the same time. In this tutorial, we will ask the tools to use a modest amount of threads, since we are sharing the headnode with eachother (and other researchers of IBED and SILS).

So, head over to the correct section, and start your genome assembly job.

flye: assembly for long reads

If you have long reads, run a flye assembly like this:

flye --nano-raw data/dataset_XY.fastq --genome-size 5M --out-dir flye-assembly --threads 4

It could take a while!

Let’s have a look at the output:

ls flye-assembly/

There are 5 subfolders which contain a lot of intermediate files, we don’t need them today (although you can look at them if you want). Important files are:

  • assembly.fasta: the actual genome assembly
  • assembly_info.txt: small text file with info of each contig
  • flye.log: the full log file of the flye run. There’s a lot of info, but some useful results can be found at the very end of the file.

Take a moment to inspect the files with your toolkit of unix commands (cat, head, tail, seqkit, etc).
